# Spreads on Toast — Product Redesign & Brand Evolution

## Mission

The engineering foundation is complete.

Do **not** spend this effort on backend refactoring, security reviews, API redesign, or architectural cleanup unless required to support the new experience.

Instead, approach this project as a **Creative Director, Senior Product Designer, Staff UX Designer, Design Systems Lead, and Frontend Architect**.

Your goal is to transform Spreads on Toast into a product that people are excited to install, use daily, and share.

Assume the existing functionality works. Challenge everything about how it is presented.

Nothing is sacred except:
- Core gameplay
- Existing data
- Digital sign API compatibility
- Existing business rules

Everything else may be redesigned.

## Success Criteria

The reaction after launch should be:

> "Wow. This doesn't look like an internal side project anymore."

Design for delight, personality, clarity, speed, confidence, mobile-first usability, and premium craftsmanship.

## Inspiration

Study the interaction principles (not the visuals) of:

- Apple Sports
- MLB At Bat
- The Athletic
- ESPN
- FanDuel
- DraftKings
- SofaScore

- Raycast

## Brand First

Before changing UI, create:

- BRAND.md
- DESIGN_SYSTEM.md
- DESIGN_DECISIONS.md

Define:
- Brand personality
- Voice & tone
- Typography
- Color system
- Grid & spacing
- Motion language
- Iconography
- Component philosophy
- Accessibility principles

## Reimagine the Product

Treat the app as three products:

### Draft Day
Make preseason picks feel exciting with large team branding, Vegas lines, progress, deadlines, and satisfying lock interactions.

### Daily Baseball
Create a fast, beautiful home for schedules, scores, standings, pitchers, and future weather/trends.

### League Competition
Make standings addictive with movement, biggest wins, biggest misses, and league insights.

## Mobile First

Assume 90% of usage is on phones.

Everything should feel native:

- Great PWA experience
- Thumb-friendly navigation
- Safe areas
- Dark mode
- Smooth motion
- Delightful transitions

## Component Audit

Replace any mediocre component.

Review:

- Navigation
- Cards
- Buttons
- Forms
- Pick selectors
- Team rows
- Charts
- Dialogs
- Toasts
- Empty states
- Loading states

## Personality

This should feel like a baseball product—not an admin dashboard.

Lean into the name "Spreads on Toast" with subtle personality and memorable branding.

Summarize:

## Guiding Principle

Don't make the app merely better.

Make it remarkable.

Design the best independent baseball prediction app on the internet.
